**PureCinepix** is a lightweight movie and TV shows downloading platform built with PHP, MySQL, HTML, CSS, and JavaScript. It provides categorized content browsing, featured sections, search functionality, user authentication, watchlist system, user comment options, and an admin dashboard for managing content and site settings. The platform is designed to be simple, fast, and easy to deploy.


**Live Website**: https://purecinepix.netlify.app/ (This URL will redirect to the main website)


**Configurations**
1. Change DB configurations in _config/config.php_ file.
2. Change API keys, email accounts in _config/constants.php_ file.
3. The included _purecinepix_db.sql_ file contains the database structure only, along with the website core settings.
